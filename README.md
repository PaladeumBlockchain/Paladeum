Paladeum Core
=====================================

Paladeum is an experimental digital Proof-of-Stake currency that enables instant payments to
anyone, anywhere in the world. Paladeum uses peer-to-peer technology to operate
with no central authority: managing transactions and issuing money are carried
out collectively by the network. Paladeum Core is the name of open source
software which enables the use of this currency.

For more information, as well as an immediately useable, binary version of
the Paladeum Core software, see https://paladeum.io.
